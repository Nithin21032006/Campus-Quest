# 🎓 CampusQuest

CampusQuest is a student-friendly web application designed to help KCET aspirants find the most suitable engineering colleges in Bangalore. The platform provides college filtering, comparison, shortlisting, and AI-based recommendations in one place.

---

## 🚀 Features

- Filter engineering colleges based on KCET rank
- Compare colleges side by side
- Shortlist and save favorite colleges
- AI assistant for personalized guidance
- Responsive and modern user interface

---

## 🛠️ Technologies Used

- HTML5 – Structure and content
- CSS3 – Styling and responsive layout
- JavaScript – Application logic and interactivity
- Font Awesome – Icons and UI enhancements
